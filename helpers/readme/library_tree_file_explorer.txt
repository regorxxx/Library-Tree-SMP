Library-Tre-SMP panel can be used as a File Explorer by setting the
appropriate source at Settings\Source submenu.

Shortcuts:
------------
• Enter: Send to current playlist.
• Shift + Enter: Add to current playlist.
• Ctrl + Enter: Send to new playlist.
• Home|End: Scroll to top|Scroll to bottom.
• Up|Down: Navigate tree.
• Left|Right: Collapse|Expand node.
• Alt + Up: Jump to first node within same level.
• Alt + Down: Jump to last node within same level.
• Num *: Expand current node.
• Num -: Collapse all nodes.

Menus:
------------
• R. Click on Root, Favorites or Computer to open associated menus.

UI:
------------
• L. Click Horizontal dragging for horizontal scrolling.
• Mouse Wheel for vertical scrolling.
• L. Click on + marker or node icon to Collapse|Expand node.
• Same mouse actions than any other source (check Behaviour tab).

TF:
------------
• foobar2000 like expressions with custom variables.
• Values enclosed on brackets ([%VAR%]) are only shown if present.
• Escape brackets to show them on expressions. i.e. '['%VAR%']'

General notes:
--------------
• File parsing can be done with ActiveX or JS-Host methods. Unix users
  will surely prefer JS-Host methods to avoid errors on Wine.

• Long paths (> 256 chars) are not supported and will show as empty
  folders. This is a Windows limitation.

• Shortcut folders, or mounted drives as folders may not work
  in some cases. This is a Windows limitation.

• Files added to foobar2000 on Dbl. L. Click are managed by foobar2000
  itself and configured at preferences ('Shell integration'). File
  Explorer filter settings is ignored in this case.

• Actions via menus which send [found] tracks to playlist will respect
  filter settings and send tracks found only on parent folder,
  without nesting or recursion (contrary to Dbl. L. Click).

Differences with WSH Tree Explorer:
------------------------------------------
• Performance improvements, code cleanup and a lot of fixes.

• Async file/folder size calculation.

• Support on Unix systems with native JS-host methods.

• Support for video files.

• Configurable mouse actions.

• Configurable mouse actions and expanded context menus.

• Configurable TF to display node labels.

• Icon effects on open/close.

• Folders's contents can be loaded without first opening them.
